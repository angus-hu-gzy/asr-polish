## v0.9.2 — 现在 `pip install asr-polish` 就能装

**代码没有功能变化。** 这一版只做一件事：把包发到 PyPI。

```bash
pip install asr-polish
pip install "asr-polish[bilibili]"   # 无字幕视频要转写时才需要（引入 yt-dlp）
```

装了就能直接用，不用 clone 仓库、不用 `-e`。

### 为什么首发是 0.9.2 而不是 0.9.1

0.9.1 的 README 里还写着「当前尚未发布 PyPI」。这句话会随元数据嵌进 PyPI 页面，
而 PyPI **不允许修改已发布版本的元数据**——先把说明改对，再发。0.9.1 从未公开，
所以 PyPI 上的第一个版本就是 0.9.2。

### 发布是自动的，而且不需要 token

`.github/workflows/publish.yml` 走 OIDC 信任发布：推 `v*` 标签自动发，也可以在 Actions
页面手动指定标签补发。发布前会校验「标签 = `__version__` = CHANGELOG」，再查该版本在
PyPI 上是否已存在（已存在就跳过，不重复上传）。

### 测试

264 项，未变。`twine check` 两个产物通过；发布后在全新虚拟环境里实跑了
`pip install asr-polish`，`asr-polish --version` → `0.9.2`，`correct "用接生解析数据"`
→ `用JSON解析数据`。

PyPI 项目页：https://pypi.org/project/asr-polish/
