## v0.6.1 — 把项目补完整

0.6.0 给了「取字幕」的能力，这一版补的是围绕它的工程面与可复现性。

### 新增

- **`subs --search <关键词>`**：按关键词搜一批视频再抓字幕，`--search-pages N` 控制搜几页。
  标题里的 `<em>` 高亮会先清掉再进文件名，否则文件名会带一堆尖括号。
- **`tools/collect_corpus.py`**：采集 AI 字幕语料，`--keywords` 搜索采集或 `--candidates` 指定清单。
  只收 `lan == ai-zh`——人工字幕的文本本身是对的，混进语料会污染召回统计；多 P 视频取最接近 20 分钟的那集。
  增量写 `manifest.json`。**基准报告里的数字从此可以在仓库内复现。**
- **`CHANGELOG.md` / `CONTRIBUTING.md` / `docs/`**：逐版本变更记录（含每版实测数字）、
  贡献流程、两份测量报告全部入仓。
- **CI `tag-check`**：标签名 = `__version__` = `CHANGELOG` 条目，三者不一致直接红。
  这条规则来自 0.5.6 的教训：那次只在文档里记了新版本，代码里的版本号没跟上。

### 修复

- **README 承诺的 Cookie 路径，代码只实现了一条。**
  文档列了三条自动查找路径，实际只查 `~/.workbuddy/...`，
  `~/Downloads/www.bilibili.com_cookies.txt` 与 `~/.config/asr-polish/cookies.txt` 从未被搜过。已补齐。
- **CI 一直漏跑测试。** 测试步骤写死了两个文件名，`tests/test_export.py` 的 16 项从未进过 CI。
  改为 `unittest discover`，新增测试文件自动纳入。
- **`export.py` 有一个未使用的 `typing.Optional`**，lint job 会红。

### 变更

- 测试 **87 → 89**（新增 `_strip_em`、语料选片逻辑）
- CI 新增「装轮子再验一次」：`pip install dist/*.whl` 后在包外目录 import，
  确认词表随包进、入口点可用

### 安装

```bash
pip install git+https://github.com/angus-hu-gzy/asr-polish.git@v0.6.1
```

### 取字幕

```bash
asr-polish subs BV1xxxxxxxxx -f txt,srt,json,md -o ./subs
asr-polish subs --up 329954990 --limit 20 -j 3
asr-polish subs --search "Rust 教程" --limit 10
```

> **需要配置 Cookie。** 游客态请求拿到的是空数组而不是报错，
> 很容易被误判成「这个视频没字幕」。见 README「Cookie 配置」。

### 边界说明

这一版没有改动订正能力，边界仍是 0.5.6 量出来的那个结论：

> 本工具是**高置信、可解释、可离线的那一小块**（术语与专名），不是字幕纠错。
> 真实 AI 字幕上实测，本工具的净修正为 **0 字**。要覆盖标点、同音词、漏句，需要语言模型。

数据与复现方式见 [`docs/真实字幕错误分析.md`](https://github.com/angus-hu-gzy/asr-polish/blob/main/docs/真实字幕错误分析.md)。
