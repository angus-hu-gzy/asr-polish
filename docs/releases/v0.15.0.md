## 这一篇讲什么

```bash
pip install -U asr-polish
```

一个两小时的视频，你未必想从头读到尾。有时候只想知道「这一篇到底讲了什么」，再决定哪几段
值得细看。

顶栏多了一个「总结」。点它，正文上方展开三块：一句话总览、核心要点、关键概念。

每条要点后面带着原文的时间。点一下，滚到那一段、闪一下；**再点一下**，视频跳到那个时间。
一次点击不干两件事——想读正文的时候，不该被拽去播放器。

### 先说清楚它花谁的钱

总结要用一个模型。设置里（顶栏「⚙ 模型」）填三样：服务地址、模型名、API key。只支持
OpenAI 兼容的接口一种。

这三样只存在你自己的浏览器里（`localStorage`），和划重点、断点续读一个路数：不落盘、不进
仓库、不进任何日志。key 跟着一次请求发到本机服务，由服务转发给你填的那家，然后就没了。

面板里明写着：**全文会发给所填的模型服务，按那个服务的计费规则花钱。** 这是你自己的学习
材料、自己的 key，这件事不该藏着。

所以它不会在你打开页面的时候偷偷调一次。点一次，花一次钱。

没配好之前，按钮上写的是「先配模型」，虚线框。点它，直接打开设置——而不是点下去才弹一句
「请先配置」。

### 一件事必须讲：时间戳是模型抄的，不是它算的

如果只是把正文丢给模型、让它自己写时间，它会写。写得很像样，然后错。长视频上稳定错几十秒，
而且错得不像错的。

所以发给模型的那份正文，每一行前面都带着原文的 `[mm:ss]`，提示词要它**原样抄行首那个时间**，
不许换算。它抄回来的每个时间，前端再拿这一篇真实的段首时间集合去比对：

- 对得上 → 渲染成可点锚点
- 对不上 → 灰字标「无出处」，不可点

宁可看着不整齐，也不给一个点了跳错地方的按钮。核对留了 1.5 秒容差——页面上的时间显示是
四舍五入的，62.7 秒显示成 `01:03`，模型把 `63` 抄回来，不留容差会把正确的锚点判成编的。

### 与任务书不一致的一处

这一层原本的设计是：前端把 `buildPlainText` 的结果发给后端。但 `buildPlainText` 是**刻意剥掉
时间戳**的那个出口——它的用途是给模型读正文，时间戳对它是噪音。

照着做，模型只能自己编时间；而功能又要求「编出来的时间判成无出处」。两条一撞，结果是**全篇
一条锚点都没有**，这功能最要紧的那一半就没了。

做法：正文仍然只从 `buildPlainText` 出（守住「全文只有一份拼法」这条），但按行对齐回
`buildFullText` 的结构，在行首补回 `[mm:ss]`——`buildSummarySource`。行数和段数对不上就整篇
不标。错位的时间戳比没有时间更糟：没有时间，你知道它定位不了；错位的时间，你以为它定位对了。

### 必剪 ASR 的篇

那些篇没有逐句时间戳。总结照常做——内容还是那些内容——但要点不带锚点，总结顶部写一句
「这一篇没有逐句时间戳，要点无法定位到视频」。

不编。`99:59:59` 那种占位值尤其不能拿来当锚点。

### 缓存

生成过的总结存在浏览器里，按任务 + 分 P 分组。下次打开同一篇，直接显示，不重新调、不重新
花钱。想换一份，点「重新生成」。

任务重跑、字幕变了，缓存自动作废——指纹取段数、字数、首尾 24 字。拿着旧总结配新字幕，
比没有总结更糟。

### 错误要说清是哪一种

没填 key、地址连不上、key 无效、模型返回错误、超时，是五件不同的事，用户要改的地方也不同。
所以错误分成八种，提供方的原话原样带回来。key 填错时你看到的是 `Incorrect API key provided`，
不是「总结失败」。

### 没变的

- 抓取、限速、风控退避、状态机、`transcript` 接口结构一行没动。
- `buildFullText` / `buildPlainText` / `buildFullMarkdown` 一行没动。
- 搜索、划重点、播放器、合集目录、断点续读、夜间模式、导出重点、导出全文，行为全不变。
  **导出重点逐字节一致**。
- 页面仍是 `reader.py` 生成的单文件 HTML，无框架、无构建步骤、核心零依赖。
- 仍然只监听 `127.0.0.1`，没有账号、不做跨设备同步。

### 测试

459 项（+52）。`tests/test_summary.py` 里有一个真的起假模型服务、把请求发过去再看回来什么：
地址拼接、八种错误的分类、提供方原话是否带回、key 是否出现在任何一条错误消息里、超时。

真浏览器 39 项：配好模型后三块出现、前两个锚点正好落在真实段首、`07:12` 是假的判「无出处」、
没给时间的也判「无出处」；刷新直接显示且假模型调用次数不变；重新生成调用 +1；必剪 ASR 篇顶部
有说明且没有可点锚点；key 错时显示提供方原话、页面源码里搜不到 key；没有产出的任务不出现工具栏。
旧功能回归 33 项全绿。
